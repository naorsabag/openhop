# Security Policy

## Reporting a Vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/naorsabag/OpenHop/security/advisories/new)
to report security issues. We aim to respond within 48 hours.

Do not open public issues for security problems.

## Supported Versions

OpenHop is pre-1.0; only the latest `0.x` release receives security fixes.
