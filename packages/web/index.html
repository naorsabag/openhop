OpenHop — animated data-flow diagrams your AI agent can write

OpenHop is an open-source playground and CLI for animated, multi-level data-flow diagrams. Your AI coding agent writes a small YAML file; OpenHop renders it as an animated diagram you can play, pause, scrub, and drill into. Local-first, token-light, MIT-licensed.

Showcase flows

  • Netflix system design
  • Spotify system design
  • browser-use agent
  • LangGraph internals
  • OpenAI Codex CLI

Install

npx openhop demo spins up the local playground with every showcase flow seeded. Full install and skill-integration docs live on the project page.
